# Favorite GIFs

A personal stash of reaction GIFs, pop culture moments, sports clips, game bits,
and general internet energy.

## What's inside

This repo is intentionally simple: it is just this catalog, the GIF collection in
`assets/`, and a couple source videos. There is no build step, package manager,
or app code.
